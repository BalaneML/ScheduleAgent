# 元の 60QA から変えたこと

元のシートは「テンプレの質問は最大公約数なので、通常 10 個程度はカスタマイズか削除する」としている。論文 L（LLM に活動スケジュールを 1 人ずつ書かせ、集計との差をメモリで返して集計表に合わせる）に合わせて、次のように変えた。質問を変えたいときは、[questions.md](questions.md) とこのファイルを一緒に直す。

この一覧は、論文 P（2 段階学習、DomainTransfer_trial）用の 2026-11-16 版を 2026-11-18 に書き換えたものである。P 版から変えた点は §5 にまとめた。

## 1. 数

| | 元の 60 問のうち | 本研究用の ID の数 |
| --- | --- | --- |
| そのまま残した | 41 | 43（4-8 を a〜c に分けた） |
| 文言を変えた | 18 | 18 |
| 削った | 1 | 0 |
| 足した | — | 12 |
| 合計 | 60 | 73 |

2-2 と 4-8 は、元のシートが「個数分コピーしてください」としている質問である。

- **2-2（N 個目の関連分野）：** 元の文言のまま 1 問にしてある（2026-11-16 のユーザーの判断）。関連分野の分け方を質問一覧で固定せず、報告書を書くときに分野の数だけ 2-2a、2-2b、… と増やす。そのため、報告書の問数は 73 より多くなる
- **4-8（N 個目の構成要素）：** 手法の 3 つの構成要素（LLM による生成・メモリ・逐次の確定）に対応させ、質問一覧の中で a〜c に分けてある。手法の構成を変えたら、枝番も直す

## 6. 論文の段落にならない質問

0-1・6-16・7-5 は進捗の報告のための質問で、論文の段落には対応しない。完了率にも数えるが、英語にする工程（□・◎）からは外す。
